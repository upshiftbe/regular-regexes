# rre

The old name of [regular-regexes](https://pypi.org/project/regular-regexes/). Installing `rre`
installs `regular-regexes`, and `from rre import rre` gives the same object as
`from regular_regexes import rre`. New code: `pip install regular-regexes`.

All regexes: [regexes.upshift.be](https://regexes.upshift.be/).
